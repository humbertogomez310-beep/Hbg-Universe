La idea correcta del Universo HBG no es crear una sola aplicación gigante, sino un ecosistema modular, donde:

Cada app funciona sola.
Cada app puede instalarse individualmente.
Cada app tiene identidad propia.
Todas pueden comunicarse entre sí.
Existe una pantalla universal para conectarse con las demás.
HBG Core es el cerebro, pero no obliga a las demás aplicaciones a depender de él.
El usuario puede compartir una sola app o todo el universo completo.

Eso hace que el proyecto sea mucho más profesional y escalable.
